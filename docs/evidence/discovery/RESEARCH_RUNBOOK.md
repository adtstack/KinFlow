## 1. 모집 단위

문제 인터뷰는 6~8가구, 성인 12~15명을 목표로 한다. 한 가구에서 coordinator만 듣지 않고 가능한 경우 초대받을 두 번째 성인을 별도 세션으로 인터뷰한다.

| Segment | 가구 목표 | 필수 조건 |
|---|---:|---|
| 자녀 없는 동거/부부 | 2 | 최근 2주 공동 집안일 사례 |
| 어린 자녀 가족 | 2 | 보호자 2명 의견 확보 우선 |
| 학령기 자녀 가족 | 2 | shared-device child mode 의견 수집 |
| 다세대·돌봄 조율 | 1~2 | 의료 기록이 핵심인 경우 제외 |

Concierge pilot은 위 인터뷰와 별도로 실제 성인 2명이 참여하는 8가구를 모집한다.

## 2. 개인정보·동의 규칙

- participant ID는 `HHxx-A`, `HHxx-B` 형식으로 기록한다.
- 이름, 이메일, 전화번호, 자녀 실명, 원문 녹취를 Git 저장소에 넣지 않는다.
- 녹음이 필요하면 별도 동의를 받고 접근 제한 저장소와 삭제일을 기록한다.
- 연구 메모에는 과거 행동을 요약하고 직접 인용은 개인 식별이 불가능한 짧은 문장만 사용한다.
- 자녀는 Phase 00 계정 사용자가 아니다. 자녀 관련 prototype에는 가명만 사용한다.
- 보상, 모집 채널, 연구자 개입을 결과에 기록한다.

## 3. 문제 인터뷰 절차

권장 시간은 30~40분이다. 제품 화면을 보여주기 전에 최근 행동을 먼저 묻는다.

1. 최근 2주 동안 반복해서 부탁하거나 확인한 가족 일을 하나 설명해 달라고 한다.
2. 처음 전달한 채널, 담당 합의, 완료 확인 방법을 시간순으로 묻는다.
3. 잘못 이해했거나 다시 재촉한 순간과 결과를 묻는다.
4. 메신저·캘린더·메모 중 계속 써야 하는 이유를 묻는다.
5. 다른 성인이 새 앱을 설치하거나 다시 열지 않을 이유를 묻는다.
6. 자녀에게 허용할 행동과 절대 허용하지 않을 행동을 묻는다.
7. 현재 도구에 돈을 냈던 경험, 해지 이유, 반복 지불 가치가 있는 결과를 묻는다.

금지 질문:

- “이 앱을 쓰시겠어요?”처럼 미래 의향만 묻기
- 기능 목록을 먼저 보여주고 필요한지 묻기
- coordinator 답변을 가족 전체 답으로 기록하기

## 4. 인터뷰 직후 기록

각 세션 후 15분 안에 `interview-notes/SESSION_TEMPLATE.md`를 복사해 작성한다.

- 최근 2주 구체 사례 존재 여부
- 재촉 빈도와 비용
- 현재 대체재와 전환 장벽
- 두 번째 성인의 참여 동기/거부 이유
- 일정+집안일 결합에 대한 실제 사례
- 자녀 모드와 공유 기기 수용성
- 지불 경험과 결과 중심 가치
- 가설을 지지하는 증거와 반증하는 증거

## 5. Clickable prototype task

화면 설명을 읽어주는 대신 시작 상태와 목표만 제시한다.

| Task | 검증 가설 | 성공 기준 |
|---|---|---|
| 가구 생성 후 배우자 초대 | H-02 | 도움 없이 초대 경로 완료, 가구 개념 설명 가능 |
| 쓰레기 배출을 반복 배정 | H-03 | 담당·마감·반복 의미를 정확히 예측 |
| 토요일 가족 일정과 집안일 충돌 확인 | H-04 | 통합 Today에서 충돌을 찾고 다음 행동 선택 |
| 공유 기기에서 자녀가 자기 할 일 완료 | H-05 | 보호자 권한과 자녀 권한을 혼동하지 않음 |
| paywall이 적용되는 가구 설명 | H-06/H-07 | 한 결제가 어느 가구에 적용되는지 정확히 설명 |
| 계정 삭제와 가구 삭제 구분 | trust | 공동 데이터 영향 차이를 정확히 설명 |

각 task에서 성공/실패, 첫 클릭, 잘못된 경로, 도움 요청, 이해하지 못한 문구, 신뢰가 깨진 순간을 기록한다.

## 6. 14일 Concierge pilot

### Day 0

- 성인 2명 동의와 participant ID 발급
- coordinator가 직접 가구를 만들고 상대를 초대
- 연구자는 초기 template 설정을 도울 수 있으나 개입 내용을 기록
- 시작 전 지난 7일의 재촉/확인 횟수 회상값 기록

### Day 1~13

- 초대 전송·수락 시각
- 두 번째 성인의 첫 독립 행동
- 생성/완료/되돌리기
- Today 방문 일수
- 앱 밖 재촉 메시지 수
- 연구자 reminder와 수동 수정 기록

### Day 14

- 두 성인을 가능하면 따로 인터뷰
- 앱 없이 처리했을 일, 앱 때문에 새로 한 행동, 믿지 못한 정보, 갈등을 늘린 표현 확인
- 데이터 삭제/보존 동의 확인
