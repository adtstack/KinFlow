# 문서·설계 Review Prompt

KinFlow 문서 변경을 다음 관점에서 검토하라.

- 제품 MVP가 너무 넓어지지 않았는가
- Flutter mobile-first 전략과 Web/Desktop Gate가 혼합되지 않았는가
- household/Managed Child/billing 권위가 client로 이동하지 않았는가
- recurrence/timezone/삭제 의미가 모호하지 않은가
- 요구사항→Phase→contract→test→evidence 연결이 있는가
- OPEN 사업/법률 결정을 구현이 추측하지 않는가
- Store/SDK/정책 정보가 최신 공식 출처로 재확인되었는가

모순, 누락, 위험, 중복을 중요도와 함께 제시하고 수정 문구를 제안하라.
