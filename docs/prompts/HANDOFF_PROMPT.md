# Phase/Work Package Handoff Prompt

현재 구현을 다음 담당자에게 인계할 수 있도록 작성하라.

- Phase/WP와 목표
- 완료된 requirement
- architecture/data/RLS/API 결정
- migration/contract/version
- 실행한 tests/build와 evidence
- 수동 console 상태
- known issues/residual risks
- feature flags/kill switch
- rollback/recovery
- 다음 WP의 정확한 시작점

추측, 개인 scratchpad, secret은 포함하지 않는다. 실패한 테스트와 임시 workaround를 숨기지 않는다.
