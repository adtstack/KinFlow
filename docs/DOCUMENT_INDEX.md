# KinFlow Flutter 문서 인덱스

## 시작 문서

- `VERSIONING_CONVENTIONS.md` — KinFlow 스펙·문서팩·Flutter SDK 버전 구분 규칙

- `START_HERE.md` — 읽는 순서와 개발 시작 방법
- `PACKAGE_INFO.md` — 문서팩 형식과 플랫폼 요약
- `MD_ONLY_FORMAT_GUIDE.md` — 코드 블록 원본 추출 규칙
- `DECISIONS.md` — 확정·미확정 제품/아키텍처 결정
- `SPEC_BASELINE.md` — 기술·품질 기준선
- `IMPLEMENTATION_PLAN.md` — Phase 00~10 실행 순서
- `IMPLEMENTATION_SPEC.md` — 코딩 에이전트용 단일 구현 스펙
- `MASTER_SPEC.md` — 제품 기획 포함 통합 스펙

## 폴더

- `docs/` — 제품·UX·도메인·기술·보안·출시·운영 문서
- `phases/` — Phase별 독립 실행 계획
- `contracts/` — SQL·OpenAPI·YAML·Dart 등 계약 원문을 담은 Markdown 래퍼
- `matrices/` — 검증 CSV 원문을 담은 Markdown 래퍼
- `prompts/` — 코딩·검토·출시 감사 프롬프트
- `templates/` — ADR·테스트·릴리스·장애 템플릿
- `migration/` — Expo 기반 스펙 v0.4에서 KinFlow Flutter 앱 스펙 v1.0으로의 전환 안내
- `evidence/` — Phase별 증거 저장 규칙
- `scripts/` — 검증 스크립트 원문을 담은 Markdown 래퍼
